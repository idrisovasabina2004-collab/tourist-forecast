# Прогнозирование загруженности туристических достопримечательностей
Код к статье: сравнение CatBoost, XGBoost и LightGBM.

## Что внутри
Один блокнот (.ipynb). В нём:
- генерация синтетического датасета;
- обучение трёх моделей и расчёт метрик;
- кросс-валидация и статтесты;
- рекурсивный прогноз на 16 дней.

## Как запустить
Установить библиотеки:
pip install catboost xgboost lightgbm scikit-learn pandas numpy scipy
Открыть блокнот и выполнить ячейки по порядку.

## Важно
В демонстрационном примере рекурсивного прогноза погодные данные заданы заглушкой (weather_forecast). В реальном приложении они поступают из API Open-Meteo.

## Воспроизводимость
Все случайные процессы зафиксированы. Метрики качества (MAPE, MAE, RMSE, R²) воспроизводятся точно. Время обучения может отличаться — оно зависит от компьютера.
